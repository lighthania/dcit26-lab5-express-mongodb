# DCIT 26 Laboratory 5: Express and MongoDB

## Project Description

This project is a Student Records API built with Node.js, Express.js, and MongoDB. It allows users to add, view, update, and delete student records.

## Technologies Used

* Node.js and Express.js
* MongoDB and Mongoose
* Postman
* GitHub

## API Endpoints

| Method | Endpoint            | Function         |
| ------ | ------------------- | ---------------- |
| GET    | `/api/students`     | View students    |
| GET    | `/api/students/:id` | Find a student   |
| POST   | `/api/students`     | Add a student    |
| PUT    | `/api/students/:id` | Update a student |
| DELETE | `/api/students/:id` | Delete a student |

## Setup

1. Install dependencies using `npm install`.
2. Configure the `.env` file with your port and MongoDB connection string.
3. Start the server using `npm start`.
4. Test the endpoints using Postman.

## Conclusion

This activity demonstrates how to create an API, connect it to MongoDB, and manage student records.
